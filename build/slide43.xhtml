Exercice 04b - TEI P5 XHTML avec paramètres

  • fichier à transformer : 01/hugo1829_dernier-jour-condamne.xml
  • éditez le scénario précédent (Oxygen vous proposera de le dupliquer)
  • dans Paramètres, modifiez numberHeadings pour désactiver numérotation des sections
  • relancez la transformation et comparez avec la sortie précédente

De nombreux autres paramètres sont accessibles et permettent de rapidement adapter la sortie : (joindre un fichier css avec cssFile, numéroter les paragraphes numberParagraphs, gérer le sommaire, etc.)

Le code des Stylesheets est modularisé pour faciliter les réutilisations. Le dossier commons par exemple contient les fichiers communs à toutes les transformations.
