Les règles intégrées

Quand aucun motif est trouvé pour un nœud, le processeur XSLT applique les règles suivantes :

  • pour les nœuds élément et document : il passe aux nœuds enfants
  • pour les nœuds texte et attribut : il sort la valeur textuelle
  • pour les nœuds commentaire et instruction de traitement : ils sont supprimés de l’arbre de sortie

voir la feuille de transformation exercices/01/defaut.xsl

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
    xmlns:xs="http://www.w3.org/2001/XMLSchema"
    exclude-result-prefixes="xs"
    version="2.0">
    
    <xsl:template match="* | /">
        <xsl:apply-templates/>
    </xsl:template>
    <xsl:template match="text() | @*">
        <xsl:value-of select="."/>
    </xsl:template>
    <xsl:template match="processing-instruction()|comment()"/>
</xsl:stylesheet>

Il n’est aucunement nécessaire d’inclure ces instructions dans une feuille de transformation !
