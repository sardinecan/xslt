Règles modèles <xsl:template/>

Une feuille de transformation XSLT repose sur l’utilisation de règles modèles (<xsl:template/>). Toute règle modèle est composée d’un motif (@match) qui identifie les nœuds à transformer et d’un modèle constitué des instructions à appliquer lorsque le motif est trouvé dans l’arbre d’entrée.

Le motif le plus simple est le nom d’un élément :


<xsl:template match="ref"><!-- @match : expression XPath -->
    <!-- modèle : le contenu de xsl:template -->
    <a href="{ @target }"><xsl:apply-templates/></a>
</xsl:template>

Les instructions sont définies par un ensemble d’éléments XSLT

  • xsl:value-of évalue le contenu textuel d’un nœud
  • xsl:apply-templates applique les règles en descendant en profondeur
  • xsl:element crée un nœud élément
  • xsl:attribute crée un nœud attribut
  • xsl:text crée un nœud texte
  • xsl:if test simple, instruction conditionnelle
  • xsl:choose test complet, série de tests exprimés par les sous-éléments xsl:when et xsl:otherwise
  • xsl:for-each boucle, itération sur un séquence de nœuds
  • xsl:for-each-group boucle, itération non pas sur un ensemble de nœuds, mais sur des groupes de nœuds
  • xsl:sort tri d’une séquence de nœuds (utilisation avec xsl:for-each et xsl:apply-templates
  • xsl:variable déclaration d’une variable
  • xsl:param déclaration d’un paramètre
