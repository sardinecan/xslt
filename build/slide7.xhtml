Une première transformation

Entrée :

 <ref target="www.w3.org/TR/xslt-30/">The <emph>XSLT</emph> Standard</ref>

Sortie :

 <a href="www.w3.org/TR/xslt-30/">The <em>XSLT</em> Standard</a>

XSLT :

  • S’il y a un élément ref alors il est transformé en élément HTML a ;
  • S’il y a un attribut @target alors il est transformé en attribut HTML href ;
  • S’il y a un élément emph alors il est transformé en élément HTML em.
