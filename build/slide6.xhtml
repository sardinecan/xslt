Transformation XSLT

  • une feuille XSLT contient des règles modèles (templates)
  • chaque règle est composée d’un motif (les nœuds à transformer) et un modèle (ce qu’on veut en faire)
  • le processeur XSLT cherche les motifs dans un document XML donné en entrée
  • si un motif est trouvé, alors le processeur écrit le modèle de cette règle dans l’arbre de destination
  • en fin de processus, l'arbre de sortie est sérialisé dans un autre document XML ou dans un autre format (XML ou non)
