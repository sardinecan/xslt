Exercice 01c - copie à l’identique

  • fichier à transformer : 01/hugo1829_dernier-jour-condamne.xml
  • feuille de transformation : 01/copie.xsl
Comment fonctionne la copie ?
  • On définit une règle pour tous les nœuds node() union @* :
    • node() : tous les nœuds sauf les attributs
    • @* tous les nœuds attributs
  • xsl:copy copie le nœud
  • xsl:apply-templates applique la même règle pour tous les nœuds fils
  • elle adopte ainsi un fonctionnement recursif
