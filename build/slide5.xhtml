XSLT dans les grandes lignes

  • XSLT est un langage de transformation pour les documents XML ;
  • Il permet de produire en sortie d’autres documents XML, mais pas uniquement ! ((X)HTML, plein texte, JSON, CSV, etc.) ;
  • Une feuille de transformations XSLT est un document XML ;
  • modulaire et extensible ;
  • pas d’ordre de traitement.
